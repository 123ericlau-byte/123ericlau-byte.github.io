Hermes Local

Hermes Local is a personal assistant that runs on a Mac. It connects to the operator's Google account to carry out requests and routines the operator configures.

Google Workspace connection

The operator can use Hermes Local to work with files in Drive, edit Docs and Sheets, manage Calendar events, and read, organize, or send Gmail. One workflow reads a church planning sheet to find the title, speaker, and scripture for a sermon recording.

To connect, start Google Workspace authorization from Hermes Local and review the permissions on Google's consent page.
